# Collection and versification

The owner's 2026-10-30 decision approves **GEN, MAT, MRK, LUK, JHN only**. See
`config/collection.yaml` and decision 0001. No wording, historical source,
metadata, commentary or publication is implicitly approved. Any new book needs
a separately dated explicit owner decision; there is no expansion milestone.

Preserve each complete approved book in the source-faithful dataset after its
exact source edition is admitted. Do not delete difficult passages. A thematic
reading path is a labelled selection that links complete contexts, not a
replacement base. External references never import an external book's full text.

Versification belongs to the exact source edition. Keep chapter/verse labels as
strings, including suffixes, bridges, alternate labels and mappings. Layout is
independent of numbering. Faithful transcription, a named ancient-language
edition, a manuscript witness and an autograph are different things; none is
called Jesus's recoverable original words by inference.

Initial pipeline coverage is compared against the reviewed per-source manifest,
not a universal verse-count table. Missing/unexpected/reordered/duplicate records
fail closed. Explicit historical absences differ from outside-source-canon,
failed download, parsing failure and not-yet-modernized text. No state is filled
from model memory or a protected modern version. Document known variants and
their witnesses without silently replacing the base reading.

The synthetic fixture has four segments under GEN test labels, including suffix
`2a`, bridge `3-4` and alternate label `2`. These are invented format tests, not
five genuine Genesis verses, a complete chapter or reviewed pilot coverage.
Actual historical coverage remains zero for every approved book.
