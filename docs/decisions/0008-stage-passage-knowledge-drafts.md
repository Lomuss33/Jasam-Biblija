# 0008: Stage passage research and annotations outside the canonical bank

Date: 2026-10-30. Status: reversible local implementation.

Complete the remaining requested manual packet types with separate passage
research and annotation protocols. Preparation must reuse exact pilot selection,
source admission and current reader text. Annotations describe displayed source
or approved wording, not an unapproved modernization.

Bind source/context, display hashes, policy, scoped knowledge metadata/content,
registered bibliography, namespace and response schema. Exclude external evidence
text bodies. Return research leads/questions separately from attributed draft
evidence/claim/annotation records. Explanatory drafts require evidence; reflection
and creative material cannot be relabelled as independent corroboration. New
support cycles are invalid; related-note cycles remain allowed.

Share a pure graph validator so candidate records can be checked jointly with
existing canonical records without temporary writes to the bank. Require new
IDs, typed references, exact current dependencies, null approval and explicit
AI-assisted attribution. Preserve uncertainty and reject human impersonation,
stale support, unrequested scope and unsupported entity/event/story expansion.

Import only separate immutable unreviewed response packages. Do not mutate
canonical knowledge, reader, source locks, flags or text decisions. Human
knowledge review/promotion and preservation of attribution are separate work.
Demonstrate with original technical fixtures while real source rights/lineage
remain unresolved. Keep the editorial-policy input and prior cached artifacts
unchanged; this is a software workflow extension, not a new linguistic rule.
