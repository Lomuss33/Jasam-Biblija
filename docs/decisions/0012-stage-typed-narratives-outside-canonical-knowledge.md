Date: 2026-10-31. Status: reversible local implementation, no owner approval.

Add three versioned self-contained draft schemas and a separate manual narrative
packet namespace. Reuse the admitted passage snapshot and evidence/claim graph
checks while preserving existing annotation packet bytes and promotion rules.
Do not change the canonical envelope or grant AI returns human authority.

Distinguish source narration, unverified historical claims and explicit fiction.
Require exact display spans, typed same-basis local references, bounded scope,
source support, separate secondary support for historical claims, attribution
and uncertainty. Restrict selected names to attached approved mappings; an
unmapped entity label must reproduce its exact mention. Preserve source reading
order without inferring chronology. Anchored asserted relations still need
human semantic inspection. Do not harmonize differing scenes or infer subjects.

Imports remain unreviewed and outside canonical knowledge, reader/search and
canonical-build archives. Human narrative review/promotion is a separate next
slice. Demonstrate only original synthetic text and separately labelled fiction;
no real source, biblical participant or historical event is created. Synthetic
name attestations used in tests exist only in automatically removed test roots.

Exact archive engine compatibility is preserved: new code/schema bytes require
a new matching engine, not an overwrite or silent migration of older snapshots.
